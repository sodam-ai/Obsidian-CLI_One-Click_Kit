# Obsidian-CLI 원클릭 키트 — `Obsidian-CLI_One-Click_Kit`

옵시디언(Obsidian) 노트를 **창을 안 열고 명령으로** 빠르게 다루는 도구
[`notesmd-cli`](https://github.com/Yakitrak/notesmd-cli)를, **컴퓨터·전자기기를 처음 다루는 분도**
한국어로 쉽게 **설치·실행·사용·제거**할 수 있게 도와주는 묶음(키트)입니다.

> 📦 GitHub 저장소: **`sodam-ai/Obsidian-CLI_One-Click_Kit`**

> 🇰🇷 **한국어 = 이 문서** · 🇺🇸 English → [README.en.md](./README.en.md)
> 📘 처음이거나 막히면 → **[왕초보_시작_가이드.md](./왕초보_시작_가이드.md)** (영어: [왕초보_시작_가이드.en.md](./왕초보_시작_가이드.en.md))
> 📄 이 문서의 PDF → [README.pdf](./README.pdf) (내용 동일)

## 0. 한눈에 (제일 급할 때)

1. `시작하기.bat` 더블클릭 → **`1` 설치하기** → 끝나면 **`2` 사용하기**.
2. 막히면 `자가진단.bat`. 지울 땐 `UNINSTALL.bat`(노트는 안 지워짐).

아래는 그 모든 단계를 **빠짐없이 자세히** 풀어 쓴 설명서입니다.

## 1. 이게 다 뭔가요? (개념 먼저)

처음 보는 용어를 쉬운 말로 풀면 이렇습니다.

| 용어 | 쉬운 설명 |
|---|---|
| **Obsidian(옵시디언)** | 글·메모(노트)를 정리하는 무료 프로그램. https://obsidian.md |
| **볼트(Vault, 노트함)** | 노트(.md 파일)들이 모여 있는 **하나의 폴더**. 예: `내노트` 폴더 |
| **.md (마크다운)** | 글자만으로 제목·목록을 표현하는 가벼운 문서 형식. 노트 한 개 = .md 파일 1개 |
| **NotesMD CLI** | 옵시디언 **창을 안 열고**, 타자(명령)로 노트를 만들고 찾고 여는 도구 |
| **CLI(명령줄 도구)** | 마우스 클릭 대신 **글자 명령**으로 쓰는 프로그램 |
| **이 키트** | 위 도구를 초보자도 **원클릭**으로 깔고 한국어 메뉴로 쓰게 해주는 묶음 |

> 핵심 한 줄: **이 도구를 쓰려면 "노트함(볼트=폴더)" 1개가 필요**합니다.

## 2. 사전 준비물 · 필요 프로그램

| 항목 | 필요 여부 | 설명 |
|---|---|---|
| **Windows 10 / 11** | 필수 | 이 키트는 Windows 전용입니다. |
| **Windows PowerShell** | 필수(이미 내장) | Windows에 기본으로 들어 있습니다. 따로 설치 안 해도 됩니다. |
| **인터넷 연결** | 필수(설치·업데이트 때) | 도구를 GitHub에서 내려받기 때문입니다. |
| **certutil · tar** | 필수(이미 내장) | Windows 기본 도구. 자동으로 쓰이며 직접 만질 일 없습니다. |
| **Obsidian + 볼트 1개** | **사실상 필수** | 노트함을 이름으로 쓰려면 옵시디언에 볼트가 등록돼 있어야 가장 쉽습니다. |

> ℹ️ **Obsidian은 "실행 중"일 필요는 없습니다.** 볼트(폴더)만 있으면 됩니다.
> 옵시디언이 없으면 메뉴에서 볼트를 정할 때 영어 오류가 납니다(아래 12번 참고).

## 3. 다운로드 방법

### 3-1. 이 키트 받기
- 이 키트를 ZIP으로 받았다면 **폴더째로 압축을 푸세요.** `lib` 폴더와 `.bat` 파일들이 **같은 폴더에 함께** 있어야 합니다.
- 파일을 하나씩 다른 곳으로 옮기지 마세요(특히 `lib` 폴더).

### 3-2. 도구(notesmd-cli) 받기 — 자동
- 설치(아래 6번)를 누르면 키트가 **GitHub 최신 릴리스에서 자동으로** `notesmd-cli.exe`를 내려받습니다.
- 출처: https://github.com/Yakitrak/notesmd-cli/releases

### 3-3. 수동 다운로드(자동이 안 될 때 대비)
1. 위 릴리스 페이지 접속 → `notesmd-cli_X.X.X_windows_amd64.tar.gz` 내려받기.
2. 압축 풀기: `tar -xzf 파일이름.tar.gz`
3. 나온 `notesmd-cli.exe`를 `%USERPROFILE%\bin` 폴더로 복사.
4. `%USERPROFILE%\bin`을 Windows 사용자 PATH에 추가.
> 보통은 자동 설치로 끝나며, 위 수동 절차는 인터넷·방화벽 문제로 자동이 막힐 때만 씁니다.

## 4. 빠른 시작 (3단계)

1. **`시작하기.bat`** 더블클릭 → 한국어 시작 화면이 뜹니다.
2. **`1` 설치하기** 선택 → 도구가 깔립니다(보통 30초~2분).
3. **`2` 사용하기** 선택 → **`1` 기본 볼트 정하기**로 노트함을 정한 뒤, 노트 만들기·검색·열기를 사용.

> 무엇부터 할지 모르겠으면 그냥 `시작하기.bat`만 누르세요. 화면이 "지금 추천"을 알려줍니다.

## 5. 고르는 법 (메뉴에서 선택하는 방법)

모든 메뉴는 **안전하고 쉽게** 고를 수 있습니다.

- **화살표 ↑ ↓** 로 항목을 움직이고 **Enter** 로 실행합니다. (번호 키를 눌러 이동도 가능)
- **그냥 Enter** 만 누르면 **★ 추천 항목**이 자동 선택됩니다. (헷갈리면 Enter!)
- **빨간색 항목 = 위험(삭제·덮어쓰기)**. 한 번 더 생각하고 고르세요. 위험 작업은 `YES`/`Y`를 따로 입력해야 진행됩니다.
- 화살표가 안 되는 환경이면 자동으로 **번호 입력 방식**으로 바뀝니다(안 깨짐).

## 6. 설치 방법 (자세히)

1. `시작하기.bat` → **`1` 설치하기** (또는 `INSTALL.bat` 직접 실행).
2. 화면에 `[1/4]`~`[4/4]` 단계가 지나갑니다:
   - `[1/4]` PowerShell 확인 → `[2/4]` 내장 도구·설치 폴더 확인 → `[3/4]` 기존 설치 확인 → `[4/4]` 다운로드·설치.
3. **`INSTALLATION COMPLETE`** 가 보이면 성공입니다.
4. 설치 위치: **`%USERPROFILE%\bin\notesmd-cli.exe`** (예: `C:\Users\사용자\bin\notesmd-cli.exe`).
5. 처음 설치 직후에는 새 터미널에서 인식되도록 PATH가 등록됩니다. 이 키트의 `시작하기`/`사용하기`는 **새 터미널을 안 열어도** 바로 작동합니다.

> 소요 시간: 보통 30초~2분(인터넷 속도에 따라 다름).

## 7. 실행 방법 (시작하기 허브)

`시작하기.bat`을 누르면 한국어 허브가 뜨고, 위쪽에 **현재 상태**(설치됨/볼트 설정 여부/Obsidian 감지)가 보입니다.

| 메뉴 | 하는 일 |
|---|---|
| **1) 설치하기** | 이 컴퓨터에 도구를 깝니다 |
| **2) 사용하기** | 노트 만들기/검색/열기 (한국어 메뉴로 이동) |
| **3) 자가진단** | 무엇이 되고 안 되는지 점검 + 결과 저장 |
| **4) 제거하기** | 도구만 삭제(노트는 안 지움) |
| **5) 쉬운 설명** | 개념을 한 번 더 풀어서 설명 |
| **0) 종료** | 닫기 |

## 8. 사용 방법 (사용하기 메뉴 15가지)

`시작하기 → 2) 사용하기`를 누르면 아래 한국어 메뉴가 뜹니다. **맨 처음엔 반드시 `1` 기본 볼트 정하기**부터 하세요.

| 번호 | 메뉴 | 무엇을 / 언제 | 실제 명령(참고) |
|---|---|---|---|
| 1 | 기본 볼트 정하기 | 맨 처음 한 번. 노트함 폴더 이름 입력 | `set-default <볼트이름>` |
| 2 | 볼트 정보 보기 | 지금 볼트 이름·위치 확인 | `print-default` / `--path-only` |
| 3 | 노트 열기 | 노트를 Obsidian·편집기에서 열기 | `open <노트>` `[--editor]` `[--section H]` `[--vault V]` |
| 4 | 오늘 일기 | 오늘 날짜 노트 만들기/열기 | `daily` `[--vault V]` |
| 5 | 빠른 검색 | 파일명으로 찾기 | `search` `[--vault V]` `[--editor]` |
| 6 | 내용 검색 | 글자(내용)로 찾기 | `search-content <단어>` `[--vault V]` `[--editor]` |
| 7 | 목록 보기 | 볼트·하위폴더 목록 | `list [폴더]` `[--vault V]` |
| 8 | 노트 내용 출력 | 노트 내용을 화면에 출력 | `print <노트>` `[--vault V]` |
| 9 | 노트 만들기/수정 | 빈/내용/덮어쓰기/덧붙이기 | `create <노트>` `[--content C]` `[--overwrite\|--append]` `[--open] [--editor]` |
| 10 | 노트 이동/이름변경 | 옮기기·이름변경(링크 자동수정) | `move <옛경로> <새경로>` `[--vault V] [--open] [--editor]` |
| 11 | 노트 삭제 | **영구 삭제(주의)** | `delete <노트>` `[--vault V]` |
| 12 | 노트 속성 관리 | 프론트매터(YAML) 보기/수정/삭제 | `frontmatter <노트> --print \| --edit --key K --value V \| --delete --key K` |
| 13 | 버전 확인 | 설치된 도구 버전 | `--version` |
| 14 | 최신 업데이트 | 최신 버전 다시 설치 | (설치 엔진 재실행) |
| 15 | 전체 도움말 | 도구 원본 도움말(영어) | `--help` |
| 0 | 뒤로 | 시작 화면으로 | — |

> 각 메뉴 안의 세부 방식(예: 기본 볼트 / 다른 볼트 / 편집기에서 열기)도 **번호 + 한 줄 설명**으로 고릅니다.

## 9. 작동 방법 (안에서 무슨 일이 일어나나 — 쉽게)

설치를 누르면 키트는 다음을 자동으로 합니다(직접 할 일 없음).

1. **GitHub에 최신 버전을 물어봅니다.**
2. Windows 내장 `certutil`로 **안전하게 설치 스크립트를 풀어** 실행합니다(긴 줄 문제 회피).
3. 받은 파일이 **진짜 실행파일인지 검사**합니다(MZ 헤더 확인).
4. 압축(.tar.gz/.zip)을 **3중 안전장치**로 풉니다: `tar.exe` → 순수 PowerShell 압축해제 → 검증.
5. `%USERPROFILE%\bin`에 넣고 **PATH에 등록**해 어디서나 쓰이게 합니다.

> 즉, 초보자는 그냥 "설치" 한 번만 누르면 됩니다. 위 과정은 전부 자동입니다.

## 12. 문제·오류 대처

**1순위: `자가진단.bat`** 을 누르세요. PowerShell·도구설치·볼트·PATH·인터넷을 점검하고
결과를 **바탕화면 `NotesMD-CLI_진단결과.txt`** 로 저장합니다. (도움을 요청할 때 이 파일을 보여주면 빠릅니다.)

### 증상별 대처
| 증상 | 원인 | 해결 |
|---|---|---|
| `lib\welcome.ps1 을 찾을 수 없습니다`(영어) | `lib` 폴더가 빠짐/이동됨 | 키트를 **폴더째로** 다시 풀고, `.bat`과 `lib`을 같은 폴더에 두기 |
| `notesmd-cli NOT FOUND` / "도구가 없다" | 미설치 | `1) 설치하기` 먼저 |
| `Vault not found in Obsidian config file` | 기본 볼트 미설정(또는 Obsidian 없음) | `2) 사용하기 → 1) 기본 볼트 정하기`에서 **폴더 이름 정확히** 입력. 옵시디언에 볼트가 있어야 함 |
| `Install failed` / `certutil decode failed` | 인터넷/방화벽/일시 오류 | 인터넷 확인 후 재시도. 계속되면 3-3 수동 다운로드 |
| `MZ header missing` | 받은 파일 손상 | 재시도(다시 내려받음). 백신/방화벽 예외 확인 |
| 글자가 깨져 보임 | `.bat`을 직접 실행했거나 콘솔 인코딩 문제 | 반드시 **`시작하기.bat`** 으로 실행 |

> 영어 오류 메시지는 도구(notesmd-cli) 원본 메시지입니다. 위 표가 그 뜻과 해결을 한국어로 알려줍니다.

| 자가진단 결과 | 바탕화면 `NotesMD-CLI_진단결과.txt` |
| Obsidian 볼트 목록 | `%APPDATA%\obsidian\obsidian.json` (읽기만 함) |

---

## 14. 제거 방법

1. `시작하기 → 4) 제거하기` (또는 `UNINSTALL.bat`).
2. 안내에 따라 **`uninstall`** 을 입력하면 진행됩니다.
3. 지워지는 것: 도구 실행파일(`bin\notesmd-cli.exe`), (있으면) Scoop 설치, PATH 등록.
4. **노트(.md)와 볼트는 절대 지우지 않습니다.** 다시 쓰려면 언제든 `INSTALL.bat`으로 재설치.
