## 0. What is all this? (1 min)

- **Obsidian** : a free app to organize notes.
- **Vault** : one **folder** that holds your notes. (e.g. a `MyNotes` folder)
- **NotesMD CLI** : a tool to create/find/open notes by command, **without opening Obsidian**.
- **This kit** : wrappers so a beginner can install and use the tool in Korean with one click.

> Key point: you need **one vault (folder)** to use this tool.

---

## 1. Prerequisites (once)

| Item | Notes |
|---|---|
| Windows 10/11 | This kit is Windows-only. |
| Internet | Needed at install time (the tool is downloaded). |
| Obsidian + 1 vault | Prepare once, as below. |

**Prepare Obsidian (recommended):**
1. Download and install from https://obsidian.md
2. Open Obsidian and **create one Vault.** e.g. name it `MyNotes`.
   - Remember this **folder name** — you'll type it later.
3. You can now **close** Obsidian. Only the vault (folder) needs to exist.

> Windows, PowerShell, certutil, and tar are already in Windows — nothing else to prepare.

---

## 2. Download (get the kit)

- If you got a ZIP, **unzip the whole folder.**
- The unzipped folder must contain `시작하기.bat`, `자가진단.bat`, the `INSTALL/RUN/UNINSTALL.bat` files, the `lib` folder, and the docs — all together.
- ⚠️ **Do not move the `lib` folder or the `.bat` files elsewhere.** They must stay together.

---

## 3. How to choose in any menu

- Use **↑ ↓ arrows** to move and **Enter** to run.
- **Unsure? Just press Enter** — the ★ recommended item is selected automatically.
- **Red item = dangerous (delete, etc.).** Think once more before choosing.
- If arrows don't work, it switches to **number input** (type the number, then Enter).

---

## 4. Install

1. In the kit folder, double-click **`시작하기.bat`**.
   - A blue Korean start screen means it's working.
   - If you see an English "Cannot find lib\welcome.ps1", re-unzip the **whole folder**.
2. Choose **`1` Install** and press Enter → installation starts.
   - Takes about 30s–2min. **`INSTALLATION COMPLETE`** means success.
3. Press any key to close, then open `시작하기.bat` again.
   - The **status** at the top should now say "installed".

> ✅ You should see: `설치 상태 : 설치됨 (notesmd-cli version vX.X.X)` (means "installed").

---

## 5. First use — set your vault

1. On the start screen choose **`2` Use** → the Korean menu appears.
2. **`1` Set default vault** → type your vault **folder name** exactly.
   - e.g. `MyNotes`
   - ✅ You should see: `[완료] 기본 볼트: MyNotes` (means "done").
   - ❌ Failed? The folder name must match **exactly** (the one created in Obsidian).

> If you see "Vault not found in Obsidian config file", that vault name isn't registered in Obsidian. Create the vault in Obsidian and try again.

---

## 6. Make your first note (first success)

1. In the Use menu choose **`9` Create/update** → type the name `FirstNote.md`.
2. For mode, pick **`1` Empty** (just Enter) or **`2` With content**.
3. Choose **`7` List** again — your `FirstNote.md` appears. 🎉
4. Try **`4` Daily note** too — a note for today's date is created.

> ✅ Success: your note's name shows up in the list.

## 7. Everyday features

| You want to | Menu |
|---|---|
| Write a new note | `9` Create/update |
| Daily memo | `4` Daily note |
| Find by file name | `5` Quick search |
| Find by text | `6` Content search |
| See all notes | `7` List |
| Print note to screen | `8` Print note |
| Rename/move a note | `10` Move/rename (links auto-fixed) |
| Manage properties (tags) | `12` Frontmatter |

> Danger: `11` Delete is **permanent** (red). You must type `YES` to actually delete.

## 8. When you're stuck (self-check + symptom table)

1. Double-click **`자가진단.bat`** in the kit folder.
2. It checks PowerShell, install, vault, PATH, and internet.
   - **[ 정상 ]** = OK, **[ 주의 ]** = check, **[ 문제 ]** = must fix.
3. A report is saved to your Desktop as **`NotesMD-CLI_진단결과.txt`**.
   - Showing this file makes it faster for someone to help you.

### Common situations
| Symptom | What to do |
|---|---|
| "tool not found" / `NOT FOUND` | Start → `1` Install first |
| `Vault not found...` | Type the exact vault folder name (created in Obsidian) |
| `Install failed` | Check internet/firewall, then install again |
| `MZ header missing` | Install again (re-downloads). Check antivirus exception |
| Garbled characters | Launch via **`시작하기.bat`**, not a `.bat` directly |
| `Cannot find lib...` | Re-unzip the **whole folder** |

---

## 9. Remove the tool (notes are safe)

1. On the start screen choose **`4` Remove** or `UNINSTALL.bat`.
2. Type **`uninstall`** to remove the tool.
3. **Don't worry — your notes (`.md`) and vaults are never deleted.** Only tool files go.
4. To use it again, reinstall anytime via `시작하기 → 1`.
